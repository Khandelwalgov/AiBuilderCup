# Intelligence Atlas — Finale visual direction

A calm research instrument with an expressive editorial front door. Midnight ink, porcelain and mint; amber means uncertainty, never failure. Georgia display headings contrast with readable system UI and Noto Sans Devanagari fallbacks. Body 16px, metadata 13–14px, controls 14px minimum.

Use a compact pale navigation rail with a dark branded masthead, sectional workspace headings, dense evidence folios and an expansive dark dependency canvas. Avoid equal-card grids. Three shared components: interactive Intelligence Map, segmented Assessment Ledger, and numbered Readiness Journey. Every numeric state derives from API results; the public landing diagram is explicitly illustrative.

Graph: deterministic staged branching from one subject through evidence/actions to versioned opportunities. Shared dependencies get a mint junction, selection highlights only actual edges. Desktop pan/zoom and fit; mobile uses the same accessible action checklist. No force simulation or fictitious matches.

On small screens use drawer navigation, stacked editorial sections and readable controls. Hindi uses relaxed line height and wraps without fixed text heights. Motion is limited to entry and selected-path transitions, disabled under reduced motion. Focus outlines, real buttons, accessible labels and textual status equivalents are mandatory.

Review passes: inspect actual screenshots first for composition, then for state/micro-detail/mobile coherence. Capture public empty states and explicitly fictional contracts separately. Record limitations honestly.
