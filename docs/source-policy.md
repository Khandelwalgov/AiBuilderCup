# Selected official-source policy

Adapter key: `depwd-pre-matric`. Registry is code-controlled; the ingestion API takes a key, never an arbitrary URL. Only HTTPS on `depwd.gov.in` and `cdnbbsr.s3waas.gov.in` is permitted. Redirects to other hosts, robots redirects/challenges, denied robots paths, CAPTCHA and blocked responses stop the run. No credentials, login bypass, CAPTCHA solving, proxy evasion or TLS disabling is used.

The [DEPwD scholarship index](https://depwd.gov.in/en/scholarship/) links the full guidelines dated 25 September 2024 and amendment dated 4 September 2025. Exact URLs are in the README and registry. The live check fetched both with status 200 and parsed 61 and 7 pages respectively. CDN `/robots.txt` returned 404; this is recorded as `not_present`, not represented as explicit permission or a legal determination. The index robots file was accessible. Review access terms and the index again before expanding use or scheduling.

The adapter fetches both files as one versioned bundle, focusing extraction on pre-matric and applicable common conditions only. It does not automatically discover later notices or other scholarship components. An authorized reviewer must inspect amendment effects, effective dates, exclusions, selection limits and completeness before publishing. No application deadline or open-round claim is inferred from notice dates.

Each file has an SHA-256, byte count, ETag/Last-Modified where present, URL and robots outcome. The bundle snapshot records original extracted page text with per-page URL and page number; its creation time records capture. Repeated checks have separate run timestamps. Original PDF bytes are bounded in memory and hashed, but not retained; text snapshots are the implemented review archive. Extraction stores model/extractor version in the run and creates only an unverified draft. Citations are verified against recorded text, not against a newly fetched mutable page.

Limits: 8 MiB per response, at most 100 PDF pages per file, 500,000 extracted characters per bundle, three retry attempts for selected transient failures (429 stops the run without a retry), bounded network timeouts, same-host redirects only. Calls serialize per source and default to a 30-second minimum interval between attempts; documents are spaced by one second and declared robots crawl delays respected. This is a small manual prototype, not a crawler or monitored comprehensive source catalogue.

Source 403/429/timeouts/network errors preserve the last published opportunity. Source status/freshness and ingestion diagnostics carry the failure. They never imply discontinuation. The Education Ministry page was excluded after a challenge/empty text response; no bypass was attempted. Additional inaccessible candidates were not integrated.
