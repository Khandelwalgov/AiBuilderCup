# Complete interaction audit — Reimagine

Audit date: 15 October 2026. Scope: every production React component in `apps/web/src`, generated FastAPI contracts and the associated domain services. Test fixtures are explicitly fictional; they do not bypass Firebase in production. This is an inventory and evidence assessment, not a claim that every control has been accepted using a real signed-in account.

## Shared behavior and evidence conventions

**N**: native keyboard activation, label and focus outline; controls wrap/stack on mobile. **D**: dirty form registry, Router blocker with discard confirmation, before-unload protection; unsaved local values survive query refresh. **Q**: React Query pending/error rendering; mutation controls disabled while pending; backend error envelope displayed without secrets. **C**: context-preserving React Router link. **E**: public external source link, opens original with `noreferrer`; captured legal language remains untranslated. **F**: fictional browser API/session contract; **B**: real ASGI/domain tests in disposable PostgreSQL schemas; **P**: local real unauthenticated HTTP acceptance. Native accessibility and responsive behavior are shared expectations; only named tests establish exercised behavior. Production Firebase popup, real account switching and reviewer acceptance remain human checks.

## Remaining acceptance boundaries

A real signed-in Firebase user and reviewer must repeat the critical path on their account. No new real private data, adult consent grants, document uploads, paid AI, cloud deploy, application submission or notification delivery was exercised. Some backend/source-defined labels and legal text remain original language; locale formatting is presentation only. Browser mocks prove interaction/request shape, while real server tests prove permission and persistence independently; they do not constitute deployed end-to-end authentication acceptance. Every major interactive surface is inventoried above; code review alone is explicitly distinguished from an executed browser interaction.
