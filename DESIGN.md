# Nightfall visual system

Warm paper (`#f6f5ef`), deep teal ink (`#183c3b`), dark navigation (`#153e3c`), sage evidence surfaces and a restrained copper focus ring. System/Inter typography avoids a remote font dependency. Body text is 14–15px, controls at least 44px; headings use a compact scale. Use clear labels rather than status by color alone.

The desktop shell keeps context navigation visible. Mobile uses the existing keyboard-operable menu and Escape dismissal. All layouts have 320px support; long source text wraps. Motion is disabled for reduced-motion preference. Cards use 15px radii and restrained borders/shadows; spacing follows 8/16/24/32px rhythm.

Dashboard emphasizes the next useful action. Discovery prioritizes search and real coverage counts. Household/business contexts have explicit creation and editing. The plan displays the same dependency data as an interactive two-column graph and accessible checklist; selecting an action reveals exact evidence. Narrow screens use a list. Simulations are prominently hypothetical and do not save facts.

Admin review leads with structured corrections, policy categories, application contexts and individual document citations. Full JSON remains an optional advanced editor. Source evidence, review history, flag acknowledgment and explicit completeness confirmation remain available. No design change grants publication authority.
